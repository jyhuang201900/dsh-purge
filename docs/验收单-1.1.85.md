## 六、还挂着的事（不粉饰）

1. **等 YG 重启 dsh**（唯一非绿项就在这里）：`--verify-live` 八项里 **6 项 ✓、1 项 ⚠（注入正文待你选）、1 项 ✗（路由）**。那条 ✗ 是 `HTTP 400 但不是 JSON` → in-host HTTP 面要重启后才接上；重启后应转 ✓。这不是缺陷，是等待人类的一步。
2. **注入正文的选择权还在你手里**：磁盘是你自己的草稿（24,163 字），插件记录与磁盘不一致 → 三选其一：`purge_override mode=adopt`（只对齐记录、不动文件）／面板「保存」／`mode=reset`（换成当前默认）。选完这一项从 ⚠ 转 ✓。
3. **关 12 的偶发敏感（约 6%）**：加 EPERM 重试后含 write-smoke 的 18 次运行红 1 次（修前约 1/3 带 EPERM），症状已变为「第二次 apply 幂等｜漂移 1 个」，复跑即绿；断言未放宽。
4. **双次 apply 污染还原点**（已定级、不改产品代码）：`backupAll` 在第二次 apply 时把旁侧与保险柜两份备份一起改写成已打补丁内容，一次性不累积；真宿主 55 份 sidecar 全部干净。
5. 刻意没做：`dsh.compatibility`、导出/按组件分包、locale 分文件、市场发布。
