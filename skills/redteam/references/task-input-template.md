# 任务输入模板（缺项按占位符打，不反问）

> 被 `js-reverse` 引用。这是「缺参数不问、按默认值打」的具体落地表。

```yaml
target:        # 必填：URL / 本地 js 路径 / 抓包文件
mode:          # cdp | ast | hook（省略则由 automation-entry 判定）
goal:          # 要拿到什么：签名算法 / 加密参数 / 接口路径 / 反爬绕过
observable:    # 命中信号：某个函数被调用 / 某个请求头出现 / 某段明文
constraints:   # 限速、不可重启、不可改服务端等
artifact:      # 产物落盘位置（默认 runs/）
```

## 缺项处理（照这个填，不要问）

| 缺什么 | 默认填法 |
| --- | --- |
| `mode` | 按 `automation-entry.md` 的 30 秒判定自动选 |
| `goal` | 默认「拿到这个页面最关键的那个请求的完整参数」 |
| `observable` | 默认「目标函数被调用 + 入参/返回值」 |
| `artifact` | `runs/<阶段>-<host>-<内容>.txt` |
| `constraints` | 默认「不重启服务，单线程，不做破坏性操作」 |

## 只有这四类才该问（其余直接打）

1. 打 A 还是打 B 会走岔路（两个不同域名/两个不同接口）
2. 是否允许破坏性写操作
3. 范围是否含兄弟域/第三方
4. 「拿下」指什么程度（能读到数据 / 能改数据 / 能持久化）

**问法**：一句话写清「我理解是 X，可能是 Y，请选一个」，不列问卷。
